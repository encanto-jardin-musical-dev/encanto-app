## Architecture Overview

**Tech Stack:**
- Next.js 15 (App Router) with React 19 and TypeScript
- Supabase for backend (PostgreSQL, Auth, Real-time subscriptions)
- TanStack React Query for server state management
- Jotai for client state management
- HeroUI for component library with Tailwind CSS
- next-intl for internationalization

**Key Architectural Patterns:**
- **Authentication**: Supabase Auth with middleware-based session management (`src/middleware.ts`)
- **State Management**: Jotai atoms in `src/lib/store/` for client state, React Query for server state
- **Data Fetching**: Custom hooks in `src/hooks/` wrapping React Query, with query definitions in `src/queries/`
- **Real-time**: Supabase real-time subscriptions for live messaging
- **PWA**: Service worker with push notifications support (`public/sw.js` generated by prebuild script)

**Database Integration:**
- Typed Supabase client using generated types from `src/types/database.types.ts`
- Client creation pattern: singleton browser client in `src/utils/supabase/client.ts`
- Server-side utilities in `src/utils/supabase/server.ts` and `src/utils/supabase/middleware.ts`

**App Structure:**
- **Feed System**: Real-time messaging feed with group filtering (`src/app/feed/`)
- **Messaging**: Direct messaging between users (`src/app/messages/`)
- **Role-based Access**: Support for parents, teachers, administrators with different group permissions
- **Push Notifications**: Firebase integration with VAPID keys for web push

## Key Patterns

**React Query Hooks Pattern:**
- Custom hooks in `src/hooks/` (e.g., `UseGetUserGroupsQuery.ts`)
- Query definitions in `src/queries/` organized by domain
- Mutations follow same pattern with `Mutation` suffix

**Component Organization:**
- Domain-specific components in `src/components/{domain}/`
- Common/shared components in `src/components/common/`
- Each major feature has its own layout and page structure

**Type Safety:**
- Database types auto-generated in `src/types/database.types.ts`
- Domain-specific types in `src/types/{domain}.types.ts`
- Typed Supabase client ensures end-to-end type safety

**Internationalization:**
- Messages and locale handling via next-intl
- Configuration in `src/i18n/request.ts`
- Provider setup in root layout with locale detection
