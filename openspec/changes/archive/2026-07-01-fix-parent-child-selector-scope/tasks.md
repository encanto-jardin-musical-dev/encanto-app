- [x] 2.4 (discovered via user report after apply) Fix a React Query cache collision in `src/hooks/UseGetUserChildrenQuery.ts`: `queryKey` was the static `['user-children']` whenever any `userID` was passed, so `UserHydrator.tsx`'s selector-populating query and every `MessageFeedCard.tsx` instance's per-sender/per-group query (which already passed `userID: sender_id`) shared the same cache entry.
